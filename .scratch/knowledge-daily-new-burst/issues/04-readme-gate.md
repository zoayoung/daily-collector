# 04: 入榜 README 门槛与 readme_dropped

**What to build:** 准备进入榜单的候选如果连 README 都没有，就不再写入入榜集。采集在增量计算与分层排序之后、取前 50 条之前，按排序顺序逐条检查 README：404 视为无 README 并剔除；其他错误保留该条并记入 `gaps`。检查设 100 次/轮预算，凑满 50 条或预算耗尽即停；预算耗尽时在 `gaps` 说明还有多少条未做检查。被剔除数量写入新增的可选统计字段 `readme_dropped`，旧产物缺该字段时继续通过校验。

**Blocked by:** 03（共享采集统计契约与 eligible 口径）

**Status:** ready-for-agent

- [x] README 检查发生在增量计算与分层排序之后、取前 50 条之前，按排序顺序进行
- [x] 每轮 README 请求不超过 100 次；凑满 50 条或预算耗尽即停
- [x] 404 响应剔除该候选；其他错误保留候选并在 `gaps` 记录
- [x] 采集统计新增可选 `readme_dropped`（非负整数），写入被剔除数量
- [x] 预算耗尽时 `gaps` 说明未做检查的候选数量
- [x] 旧产物无 `readme_dropped` 时仍通过校验
- [x] 测试通过采集与校验 CLI 验证：404 剔除、非 404 错误保留、预算上限与提前停止、旧产物兼容

**Acceptance evidence:** 回放服务器对排序靠前的候选返回 404、对另一条返回 500，采集产物剔除前者、保留后者并在 `gaps` 记录后者；把 README 预算调小可观察到“未检查数量”说明。
