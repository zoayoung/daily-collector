# 08: 校验边界入配置与截止日单一计算

**What to build:** 校验的「发布日 - 8 天」边界不再以推导常量散落在公共模块，而是从校验语义配置读取，或由配置中的新爆款窗口推导；数据归属日前 7 天的截止日收敛为一个共享函数，采集与校验同源。改窗口天数时只改一处，采集与校验同步变化。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 分层边界偏移来自校验语义配置，或由其中的新爆款窗口推导，代码中无字面 8
- [ ] 数据归属日减 7 天的截止日只在一处计算，采集与校验复用同一函数
- [ ] 修改窗口配置后，采集与校验的边界同步变化，测试覆盖
- [ ] 现有「发布日前 8 天接受任一分层」的边界容错测试仍通过

**Acceptance evidence:** 把配置中的窗口改为其他天数，不修改代码，采集的第三通道查询与校验的分层边界同时改变。
