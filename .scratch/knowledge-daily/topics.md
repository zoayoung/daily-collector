# 关注主题

采集与打标签的重点。范围关键词为草稿，随时手工增删。一个项目可同时命中多个主题；不属于任何主题的标 `[其他]`。

## AI / LLM
- 关键词：LLM、agent、harness、skill（agent skill）、上下文工程、MCP、RAG、推理、模型发布与评测
- 范围：大语言模型及应用；agent 框架、skill 与 harness 工具链（编码代理、编排框架、工具调用）；训练与推理技术

## 网络安全
- 关键词：CVE、漏洞披露、防御工具、红队、渗透测试、供应链安全、恶意软件分析、密码学、云安全
- 范围：技术向安全内容，含密码学与云安全；不含合规与管理类

## 云原生
- 关键词：Kubernetes、CNCF、容器、服务网格、可观测性、CI/CD、平台工程
- 范围：Kubernetes 及 CNCF 生态项目、云原生基础设施与工具链

## Golang
- 关键词：Go、标准库、并发、性能、编译器、运行时、生态工具
- 范围：Go 语言本身及其生态

## 数据库
- 关键词：PostgreSQL、Redis、SQLite、ClickHouse、MongoDB、向量数据库、NewSQL、存储引擎
- 范围：MySQL 和 Oracle 系除外
- 排除：MySQL、MariaDB、Percona、Oracle

## 计算机网络
- 关键词：TCP/IP、QUIC、HTTP/3、DNS、网络工具、内核网络、CDN、负载均衡
- 范围：协议、网络性能与观测工具、底层网络技术
