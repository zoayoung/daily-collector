# 05: GitHub Actions 自动运行

**What to build:** 仓库每天 00:00 UTC（08:00 UTC+8）由 GitHub Actions 无头运行同一套采集→分析→整理→渲染流水线，也支持手动触发与强制覆盖。运行前先跑单元测试；当日日报已存在时按 `force` 跳过或覆盖；成功后把日报、token 报告与每日采集产物提交回仓库；失败时上传现场产物并标红，不自动重试。模型密钥只从仓库 Secret 注入，采集与回写使用 Actions 自带令牌。

**Blocked by:** 01, 02, 03, 04

**Status:** ready-for-agent

- [ ] 工作流包含每日定时与手动触发，手动触发提供 `force` 输入。
- [ ] 当日日报已存在且未强制时跳过并成功退出，不产生新提交。
- [ ] 单元测试先于模型调用执行，失败即停止。
- [ ] 运行锁定 opencode 版本与默认模型，仓库级配置只引用环境变量中的模型密钥。
- [ ] 成功后提交当日日报、token 报告与每日采集产物；其余中间产物不入库。
- [ ] 失败时上传中间产物、不提交半成品、不自动重试。
- [ ] 入口文档补充自动运行、Secret 与提交范围；补一条 ADR 记录「GitHub Actions 无头运行流水线」。
