# 01: 严格 30 天重复窗口（采集过滤 + 校验硬闸）

**What to build:** 读者在日报里不会再看到重复窗口内出现过的项目。重复窗口按 `[今天-30, 昨天]` 计算，不含今天；判断依据只认已发布日报中的项目。采集在计算今日新增 star 之前完成过滤，校验对分析/整理产物再做一次硬闸，窗口内零例外。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 采集阶段读取已发布日报的标题行，把重复窗口内的项目从候选集中剔除，并在 `gaps` 记录剔除数量。
- [ ] 当天已发布日报不参与窗口计算，同日「重新采集并覆盖」仍可刷新当天项目。
- [ ] 校验阶段对分析/整理产物中任何窗口内项目直接报错，不论该条是否带 `repeat` 或写了新进展。
- [ ] 30 天外再次出现的项目，`repeat.last_seen` 必须等于最近一次发布日期。
- [ ] 采集与校验共用同一套窗口与历史解析口径；测试覆盖今天、30 天前、31 天前三个边界。
- [ ] 窗口内零例外，规则不依赖子代理提示词自觉。
