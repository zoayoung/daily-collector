# 02: 自由标签与按个数评分

**What to build:** 分析阶段可以按项目内容自由打标签，不再受固定主题表限制；每条建议 2–4 个标签，未打标签的条目在日报中显示为 `[其他]`。整理阶段把零散标签合并为不超过 6 组写进当日概览。校验接受任意非空标签与空数组；质量评分的「标签精度」改为按标签个数分档。固定主题表及其权限、文档引用一并移除。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 分析产物可以使用任意非空标签，校验不再出现「不在固定主题表中」的错误。
- [ ] 空标签数组可以通过校验，并在日报中渲染为 `[其他]`。
- [ ] 标签评分按 0 个、1 个、2–4 个、5 个及以上分档，分数不再依赖关键词证据或固定主题表。
- [ ] 整理阶段能把标签合并为不超过 6 组，0 命中的分组省略。
- [ ] 固定主题表被删除，分析/整理技能、agent 权限、入口文档与术语表不再引用它。
- [ ] 补一条 ADR 记录「自由标签取代固定主题」，并补 CLI 测试覆盖任意标签与标签个数分档。
