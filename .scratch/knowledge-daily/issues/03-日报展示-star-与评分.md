# 03: 日报展示总 star 与逐条评分

**What to build:** 日报的每个项目条目展示总 star（千分位）、今日新增 star、质量评分与 A/B/C 等级；标题下继续保留当日均分与等级分布。评分按名次与仓库全名对齐到条目；评分产物缺失或无效时，只省略评分部分，不编造数字，其余内容照常渲染。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 每个条目都出现「Star：总数（今日 +增量）· 评分：总分 / 等级」形式的元信息。
- [ ] 总 star 使用千分位，今日新增与采集产物一致。
- [ ] 逐条评分与评分产物的名次、仓库全名一一对应，不串条。
- [ ] 标题下保留均分与 A/B/C 分布；评分缺失时只省略评分相关部分。
- [ ] 用一份真实或合成的当日产物渲染后，star 与评分数字可逐条核对。
