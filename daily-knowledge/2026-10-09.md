## GitHub 趋势

### 1. mattpocock/skills

- 链接：https://github.com/mattpocock/skills
- 主题：[AI / LLM]
- 核心内容：Matt Pocock 开源的自用 agent 技能集，强调小型、可组合、可改造，适配任意模型；含 /grill-me、/tdd、/improve-codebase-architecture 等工程与效率技能，可直接装进 Claude Code、Codex、Copilot 等。
- 为什么值得关注：把资深工程师的日常实践沉淀成可复用技能、反对「氛围编程」，想提升编码代理产出质量可优先跟进 /grill-with-docs 与 /tdd。

### 2. deepseek-ai/deepseek-harness

- 链接：https://github.com/deepseek-ai/deepseek-harness
- 主题：[AI / LLM]
- 核心内容：DeepSeek 开源的 agent harness，基于「一切皆插件」架构、由 Cordis 支撑，处于 developer preview；支持 npx 一键起 Web UI，配套文档与 dsh-plugin 生态，迭代快且会有破坏性变更。
- 为什么值得关注：国产大模型厂商亲自下场做 agent 运行时，插件化架构值得研究；可关注其插件机制与 Cordis 设计论文，但预览期慎用于生产。

### 3. obra/superpowers

- 链接：https://github.com/obra/superpowers
- 主题：[AI / LLM]
- 核心内容：agentic skills 框架与软件开发方法论，主张把开发流程固化为可复用技能，让编码代理按既定方法工作而非随意生成。
- 为什么值得关注：与 mattpocock/skills 同赛道，可作为对比样本；若在搭建团队 agent 工作流，值得跟进其技能组织方式。

### 4. firecrawl/firecrawl

- 链接：https://github.com/firecrawl/firecrawl
- 主题：[AI / LLM]
- 核心内容：面向 AI agent 的网页数据采集工具，把网页转成适合大模型使用的结构化数据，支持抓取、爬取与检索，是 agent 联网取数的常用组件。
- 为什么值得关注：agent 落地普遍缺可靠网页数据源；做 RAG 或联网 agent 时可直接评估接入，注意抓取合规与成本。

### 5. NousResearch/hermes-agent

- 链接：https://github.com/NousResearch/hermes-agent

- 核心内容：Nous Research 的自改进 AI agent：内置学习闭环，能从经验自动创建并优化技能、检索历史会话、跨会话建模用户；可跑在 5 美元 VPS 到 GPU 集群，支持 Telegram 等多平台与多种模型后端。
- 为什么值得关注：「技能自进化 + 跨会话记忆」是 agent 长期运行的关键方向，工程完成度高；想研究持久化 agent 或自托管助手，值得深入读其 skills 与 memory 设计。
