## 今日概览

今天的榜单集中在编码代理及其外围配套：从终端代理、规格驱动到代码知识图与 token 压缩，都在改写「怎么让代理干活」；另一侧，自托管与桌面框架继续把能力留在本地。

- **AI 编码代理**：Claude Code、Codex 与 spec-kit 代表三条路线——终端直接改码、沙箱加审批、先写规格再动手；caveman 则从 token 成本侧切进来。
- **AI 代理与工作流**：Langflow 拖节点搭流程，pi 给出统一多模型 API 与 agent 循环，适合当自建底座。
- **文档与知识处理**：markitdown 把异构文档转成模型可读的 Markdown，graphify 把代码库连文档一起变成可解释的知识图。
- **生成式 AI 与本地推理**：ComfyUI 用节点图组织扩散生成，复杂流程复现与批量出图更可控。
- **自托管与隐私**：RustDesk 与 Immich 把远程桌面和照片备份搬回自己的机器，数据不必经过第三方。
- **桌面与跨平台**：Tauri 复用系统 WebView，用 Rust 换更小的包体与更低的常驻内存。
