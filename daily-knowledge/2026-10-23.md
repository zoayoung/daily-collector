## 今日概览

今日热度集中在「把分散的 AI 工具收拢成一处」：代理编排、配置切换与跨会话记忆占据前列，设计协作与自托管入口紧随其后，老牌框架靠稳定体量留在榜上。

- **AI 编码代理与治理**：Orca、cc-switch、claude-mem、gstack 与 Paperclip 分别补调度、配置、记忆与审批预算，指向代理规模化后的管理缺口。
- **AI 设计与协作**：ui-ux-pro-max-skill 给代理补设计规范，open-design 把多形态产出与评审收进同一画布。
- **后端与 API 框架**：Supabase 用 Postgres 包住鉴权、存储与实时能力，FastAPI 仍是 Python 服务的高频起点。
- **内容生产与聚合**：MoneyPrinterTurbo 把短视频流水线工程化，iptv 提供全球公开频道清单，两者都强调可替换与可校验。
- **自托管与本地推理**：open-webui 做团队统一模型入口，llama.cpp 撑起端侧与离线推理，数据自持仍是主线。
- **桌面与网络工具**：clash-verge-rev 以 Tauri 统一三平台代理管理，是这个品类里仍在维护的图形客户端。
