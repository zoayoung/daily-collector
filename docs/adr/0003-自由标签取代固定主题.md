# 自由标签取代固定主题

原先的 `.scratch/knowledge-daily/topics.md` 用 6 个固定主题与关键词决定项目归类和评分证据：不在表内的内容被裁掉，超出预设方向的项目也拿不到标签分。这与「按兴趣全面学习」的目标冲突，而且每加一个方向都要同时改文档、校验脚本与评分规则。

现在删除主题表：分析阶段按项目内容自由打标签（建议 2–4 个，无法归类时用空数组），校验只要求标签是非空字符串且不重复；「标签精度」改为只按标签个数分档（0 个 0 分、1 个中档、2–4 个满分、≥5 个降档），分值与上限全部放在 `config/score-rules.json`。整理阶段把零散标签合并为不超过 6 组写进概览，组名可以不对应任何单个标签，0 命中直接省略。

代价是标签质量更依赖分析阶段的判断，跨天比较也不再有统一词表可依；换来的是不预设学习范围、新增方向无需改配置，并且评分不再因「标签是否命中关键词」而误伤。今后若需要引导，只在技能正文里给标签建议，不恢复白名单。
